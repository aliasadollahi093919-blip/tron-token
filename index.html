مرحله ۲: لوگو و متاداتا (IPFS)

لوگو باید روی IPFS آپلود شود تا در TronScan، دکس‌ها و کیف‌پول‌ها نمایش داده شود.

📤 آپلود رایگان روی Pinata (IPFS)

  1. 1
    به app.pinata.cloud بروید → Sign up (رایگان ۱GB)
  2. 2
    Files → Upload → logo.png (۲۵۶×۲۵۶، PNG شفاف)
  3. 3
    فایل metadata.json بسازید و آپلود کنید (نمونه زیر)
  4. 4
    CID فایل metadata را کپی کنید → فرمت: ipfs://QmXxx...metadata.json

📋 قالب metadata.json

{
  "name": "My Token",
  "symbol": "MTK",
  "description": "My TRC-20 token with logo",
  "image": "ipfs://QmLogoHashHere",
  "decimals": 18,
  "website": "https://example.com",
  "social": {
    "twitter": "https://twitter.com/yourhandle",
    "telegram": "https://t.me/yourgroup"
  }
}
